# financial-dashboard — เปรียบเทียบงบการเงิน · DBD

แดชบอร์ดเปรียบเทียบงบการเงินบริษัทกลุ่มโรงปาล์ม / โรงพืช (ข้อมูลรูปแบบ DBD)
เว็บจริง: https://sadayu07ktc-droid.github.io/financial-dashboard/

## โครงสร้าง

ไฟล์เดียวจบ — ไม่มี build step, ไม่มี npm, ไม่มี backend

```
index.html    HTML + CSS + JS + ชุดข้อมูลสำรอง อยู่ในไฟล์เดียว
README.md     ไฟล์นี้
```

GitHub Pages เสิร์ฟ static ตรงๆ จาก branch `main`
ไลบรารีภายนอกโหลดจาก CDN แค่ 2 ตัว: **Chart.js 4.4.1** (กราฟ) และ **PapaParse 5.4.1** (อ่าน CSV)

## ข้อมูลมาจากไหน — 3 ชั้น

เรียงลำดับความสด มากไปน้อย:

| ชั้น | ที่มา | ใช้เมื่อ |
|---|---|---|
| 1 | **Google Sheet (Publish to web → CSV)** | ปกติ — ดึงใหม่ทุกครั้งที่เปิดหน้า |
| 2 | **แคชใน localStorage** (`dbdCacheMain`, `dbdCacheGroup`) | ดึงชีตไม่ได้ — ใช้ข้อมูลครั้งล่าสุดที่ดึงสำเร็จ |
| 3 | **ชุดข้อมูลฝังใน `index.html`** (`ALLDATA`) | เปิดครั้งแรกและดึงชีตไม่ได้ / เปิดแบบ offline |

ชั้นที่ 2 ยังถูก hydrate ตั้งแต่เฟรมแรกก่อนยิงเน็ต ทำให้หน้าขึ้นข้อมูลล่าสุดทันทีโดยไม่ต้องรอโหลด

**badge มุมขวาบนบอกที่มาเสมอ** — เขียว = ต่อชีตได้ (พร้อมเวลาที่ดึง), เหลือง = ใช้แคช/ข้อมูลในไฟล์, แดง = ดึงไม่ได้และไม่มีแคช
กดที่ badge เพื่อลองดึงใหม่ได้ทันที และระบบจะลองใหม่เองอัตโนมัติสูงสุด 4 ครั้ง (20s → 80s)

### ชีตต้นทาง

ตัวแปรอยู่ที่หัวส่วน `<script>` ใน `index.html`

- `SHEET_CSV_URL` (gid=1324557141) — งบการเงินหลัก 24 คอลัมน์
- `GROUP_CSV_URL` (gid=159947193) — ชีต `Company_DATA`: กลุ่ม/ประเภท, แบรนด์, โลโก้

จับคู่บริษัทด้วยเลขนิติบุคคล (ตัดอักขระที่ไม่ใช่ตัวเลขและ 0 นำหน้าออก — ดู `_idkey()`)
คอลัมน์โลโก้ถ้าใส่เป็นโดเมน ระบบจะแปลงเป็น favicon ให้เอง

### กัน CORS

`_fetchCsv()` ไล่ยิงตามลำดับจนกว่าจะได้ CSV: ยิงตรง → allorigins → corsproxy.io → codetabs
ทำ 2 รอบ พร้อม cache-buster `_cb=<timestamp>` ถ้าเส้นทางไหนคืน HTML แทน CSV จะถือว่าไม่ผ่าน (มักแปลว่ายังไม่ได้ Publish to web)

## อัปเดตชุดข้อมูลสำรองในไฟล์

ชั้นที่ 3 จะเก่าลงเรื่อยๆ ตามเวลา ควรรีเฟรชเป็นระยะ (เช่นทุกครั้งที่ชีตเพิ่มบริษัท/ปีใหม่)

1. ดึง CSV จาก `SHEET_CSV_URL` แล้ว map ผ่าน `mapSheetRows()` ให้ได้ array เดียวกับ `ALLDATA`
2. แทนที่ทั้งบรรทัด `let ALLDATA=[...]`
3. แก้ `EMBED_DATE` ให้เป็นวันที่ที่ดึง — ค่านี้โชว์บน badge ให้ผู้ใช้รู้ว่าข้อมูลสำรองสดแค่ไหน

## UI

ทุกสี**ผ่านตัวแปรธีม** ห้าม hardcode ในชิ้นส่วน ไม่งั้นอีกโหมดพัง — token ชุดเดียวคุมทั้งแอป

- `:root` = โหมดสว่าง (ค่าเริ่มต้น) · `:root[data-theme=dark]` = โหมดมืด
- ครั้งแรกตามเครื่อง (`prefers-color-scheme`) เลือกเองแล้วจำใน localStorage (`fdb_theme`)
- ปุ่ม 🌙/☀️ มุมขวาบนโชว์ **สิ่งที่จะเปลี่ยนไป** ไม่ใช่สถานะปัจจุบัน
- ถ้าจะเปลี่ยนชุดสีทั้งแอป (เช่นไปเป็นธีม SSB ม่วง #33348f) แก้แค่สองบล็อก token ไม่ต้องไล่แก้ชิ้นส่วน

`--onacc` = ตัวอักษรบนพื้นสีเน้น (พลิกตามธีม) · `--ondot` = ตัวอักษรบนสีพาสเทลของบริษัท/ปี (เข้มเสมอ เพราะพื้นหลังมาจาก PALETTE ที่สว่างทั้งคู่)

### ข้อควรระวังตอนสลับธีม

Chromium **ไม่คำนวณค่า `var()` ใหม่** ให้ element ที่มี `transition` เมื่อ custom property บน `:root` เปลี่ยน — สีจะค้างของเดิมจนกว่าจะ reflow
`applyTheme()` จึงใส่คลาส `.no-anim` (ปิด transition ทั้งหน้า) → สลับ → บังคับ reflow → ถอดคลาสคืนใน 2 เฟรม **อย่าเอาออก**

ด้วยเหตุผลเดียวกัน `body` ต้องใช้ `background-color:var(--bg)` ไม่ใช่ shorthand `background:`

### component กลาง (vanilla ไม่มี lib)

| ใช้ | แทน | หมายเหตุ |
|---|---|---|
| `toast(msg[,type[,ms]])` | `alert()` | เดาชนิดจากข้อความได้ — ok / error / warn / info |
| `await confirmModal({title,msg,okText,danger})` | `confirm()` | การกระทำที่เสียของให้ `danger:true` = ปุ่มยืนยันสีแดง |
| `loader(icon,msg,skel)` / `sk()` / `skRows()` | ข้อความ "กำลังโหลด…" เปล่าๆ | วงแหวนหมุน + อิโมจิเด้ง + จุดวิ่ง |

**ห้ามใช้ `alert/confirm/prompt` ของเบราว์เซอร์** — ดูโบราณและไม่เข้าธีม

เรื่อง loading: หน้านี้มีข้อมูลโชว์ตั้งแต่เฟรมแรกเสมอ (แคช → ข้อมูลในไฟล์) จึง **ไม่เอา skeleton ไปทับข้อมูลที่ดีอยู่แล้ว** ระหว่างรีเฟรชเบื้องหลัง — ตรงตามกฎ "มีแคชแล้วรีเฟรชเงียบๆ" ที่ใช้อยู่
skeleton ใช้แค่ตอนหน้ายังไม่มีอะไรจริงๆ (โครงจางใน `#pool` / `#rankList` ก่อน JS วาดเสร็จ) ส่วนตอนดึงชีต badge จะขึ้นวงแหวนหมุนแทนจุดกะพริบ

## รวมยอดเครือสุขสมบูรณ์

มุมขวาของหัวข้อ **จัดอันดับ Ranking** มีการ์ดสรุปยอดรวมของ 4 บริษัทในเครือ
(พืช · ปาล์ม · สกล · บ่อไร่ — จับจากชื่อที่ขึ้นต้นด้วย "สุขสมบูรณ์" ไม่ได้ fix รหัสไว้
ถ้าชีตเพิ่มบริษัทในเครือ จะรวมให้เอง)

- ยอดเปลี่ยนตามหัวข้อใน dropdown และตามปี/ช่วงปีที่เลือก
- ป้าย `#N / M` = ถ้าเอายอดรวมไปแทรกในลิสต์ที่กำลังโชว์ จะอยู่อันดับไหน
  (ขอบการ์ดเป็นสีเน้นเมื่อได้อันดับ 1)
- เอาเมาส์ชี้ที่ชื่อ (มือถือ = แตะ) จะเห็นยอดแยกรายบริษัทตามลำดับ พืช · ปาล์ม · สกล · บ่อไร่

### วิธีรวมยอด — สำคัญ

**ยอดเงิน** (รายได้รวม, กำไรสุทธิ) = บวกกันตรงๆ
**อัตราส่วน** (ROA, D/E, จำนวนวัน) = คำนวณจาก**งบรวม** เช่น `ROA = Σกำไรสุทธิ / Σสินทรัพย์รวม`
ไม่ใช่เอาอัตราส่วนรายบริษัทมาเฉลี่ย ซึ่งจะให้ค่าผิด — ปี 2568 ROA งบรวม = 18.1%
แต่ถ้าเฉลี่ยอัตราส่วนจะได้ 27.8%

`r9` (การหมุนเวียนเจ้าหนี้ ครั้ง/ปี) เป็นอัตรา ไม่ใช่ยอด จึงถ่วงน้ำหนักด้วยรายได้แทนการบวก

⚠️ ยอดรวมนี้ **ไม่ได้ตัดรายการระหว่างกัน** (intercompany) ถ้าบริษัทในเครือขายของให้กันเอง
รายได้รวมจะนับซ้ำ — ใช้ดูขนาดคร่าวๆ ได้ แต่ไม่ใช่งบการเงินรวมตามมาตรฐานบัญชี

### ชิป "ในเครือ"

ชิปด่วนในกล่องบริษัท เลือกบริษัทในเครือทั้ง 4 ตัวเข้ากล่องเปรียบเทียบทีเดียว
เรียงตามลำดับ พืช · ปาล์ม · สกล · บ่อไร่

### กราฟแนวโน้ม (กดที่การ์ด)

กดการ์ดรวมยอด → เปิดกราฟเส้นแนวโน้มรายปีของเกณฑ์ที่เลือกอยู่

- **SVG + vanilla JS ล้วน ไม่ใช้ chart library** (Chart.js ในหน้านี้ใช้กับกราฟแท่ง/โดนัทเท่านั้น)
- เส้นสมูทแบบ Catmull-Rom แปลงเป็น cubic bezier (`_smooth()`) เส้นรวมของเครือหนากว่า
  และมีพื้นไล่สีใต้เส้น ส่วนอีก 4 เส้นเป็นบริษัทรายตัวใช้สีประจำบริษัท
- ชี้/แตะบนกราฟ → เส้นตั้ง + จุดบนทุกเส้น + กล่องสรุปค่าทุกบริษัทของปีนั้น
- คลิกจุด → ตารางด้านล่างเลื่อนไปแถวปีนั้นแล้วไฮไลท์
- กด legend เปิด/ปิดเส้นได้ แกน Y ปรับสเกลตามเส้นที่เปิดอยู่ (ต้องเหลืออย่างน้อย 1 เส้น)
- แกน Y ไม่ลงต่ำกว่า 0 ถ้าข้อมูลเป็นบวกล้วน แต่ถ้ามีค่าติดลบจริง (เช่น ROA บ่อไร่ ปี 2566)
  จะแสดงติดลบตามจริง

**กับดัก:** SVG ฝังสีเป็น attribute ตอนวาด ไม่ได้อ่าน CSS variable สดๆ ถ้าสลับธีมขณะกราฟ
เปิดอยู่ สีจะค้าง — `repaintCharts()` จึงเรียก `drawTrend()+wireTrendHover()` ซ้ำถ้าพบ `#trSvg`
และ `drawTrend()` อ่าน `cssv('--acc')` ใหม่ทุกครั้ง **อย่าย้ายไปกำหนดสีตอนสร้าง series**

## การ commit

แก้ไฟล์ในเครื่องแล้ว commit จากเครื่อง อย่าแก้ผ่านหน้าเว็บ GitHub — history เดิมเป็น `Update index.html` ทุก commit เลยไล่ย้อนไม่ได้ว่าแก้อะไร

เขียน message ให้บอก "แก้อะไร" เช่น

```
fix: ตัดอัตราส่วน D/E ที่ซ้ำกัน 2 แถวออก
feat: แคชข้อมูลชีตใน localStorage กันตอนโหลดไม่ได้
data: อัปเดตชุดข้อมูลสำรองเป็นของ 23 ส.ค. 2569
```
